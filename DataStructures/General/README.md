# General Algorithms and Designs

This directory contains a diverse collection of problems involving mathematics, geometry, string manipulation, and object-oriented design.

## 🗂️ Categories

### 🧮 Mathematics
- **[Prime Numbers](./math_prime_numbers.c++)**: Sieve of Eratosthenes and primality testing.
- **[Power (x^n)](./math_pow_x_n.c++)**: Binary Exponentiation.
- **[Reverse Integer](./math_reverse_integer.c)**: Handling 32-bit overflows.
- **[Rand7 using Rand5](./math_implement_rand7_using_rand5.c)**: Rejection sampling.
- **[Weighted Random Pick](./math_weighted_random_pick.c++)**: Prefix sums with binary search.

### 📐 Geometry
- **[Bishop Attack Sum](./geometry_bishop_attack_sum.c++)**: Diagonal prefix sums on a chessboard.
- **[Rectangle Overlap](./geometry_rectangle_overlap.c)**: Axis-aligned bounding box intersection.
- **[Is Rectangle](./geometry_is_rectangle.c++)**: Distance-based property verification.

### 🧵 String Manipulation
- **[Atoi](./string_math_atoi.c++)**: String to integer conversion with edge cases.
- **[CamelCase to Snake_case](./string_camel_case_conversion.c)**: Format transformation.
- **[Eliminate Substrings](./string_eliminate_specific_substrings.c)**: Single-pass in-place character removal.
- **[Remove Duplicates](./string_remove_duplicates.c)**: In-place removal using frequency tracking.

### 🎨 System & Game Design
- **[LRU Cache](./cache_lru_implementation.c)**: C implementation using a doubly linked list.
- **[Tic-Tac-Toe](./design_tic_tac_toe.c)**: State management and win-condition checking.
- **[Remote Control Keyboard](./design_remote_control_keyboard.c)**: Pathfinding on a grid-based interface.

### 🔍 Search & Optimization
- **[Rat in a Maze](./backtracking_rat_in_maze.c)**: Classic backtracking pathfinding.
- **[Two Sum](./hashmap_two_sum.c)**: Finding pairs with a target sum (Sorting + Two Pointers).
- **[Kth Smallest Element](./sorting_kth_smallest_element.c++)**: Selection using sorting or heaps.
  - [Selection Algorithm (Wikipedia)](https://en.wikipedia.org/wiki/Selection_algorithm)
  - [GeeksforGeeks Guide](http://www.geeksforgeeks.org/kth-smallestlargest-element-unsorted-array/)
